

Generating TypeScript code from the protobuf definitions:
```bash
pnpm exec protoc --ts_out src/generated --ts_opt server_grpc1 --ts_opt ts_nocheck --proto_path . proto/streaming.proto
```

Generated files in `src/generated/proto`:
- `streaming.ts`: message types and enums
- `streaming.client.ts`: client (used with `GrpcTransport`), generated by default
- `streaming.grpc-server.ts`: grpc-js server definition (`server_grpc1`)
